# 发版看板（本地前端发版管理）- 版本管理

按后端人员分组，跟踪各前端项目的发版情况（打包状态、版本号、进度等）。纯本地运行，数据保存在当前目录的 `data.json`，可用 Git 管理、团队共享。

## 启动

在仓库根目录执行：

```bash
yarn om
```

打开浏览器访问 http://localhost:3000

## 目录结构

```
server.js    零依赖 Node 服务（静态托管 + /api/data 读写）
index.html   页面（Tailwind + 原生 JS）
data.json    数据文件（Git 会追踪）
```

## 使用

- 按负责人分组管理项目，每个项目可记录：项目名、打包状态（未开始/进行中/已完成）、版本号、本周新功能、本周修复问题、进度说明、备注
- 新增 / 重命名 / 删除负责人分组
- 新增 / 编辑 / 删除项目；点打包状态徽标可循环切换状态
- 顶部统计项目总数与各状态数量；可搜索过滤
- 所有修改即改即存；支持导出 JSON 备份、导入恢复
